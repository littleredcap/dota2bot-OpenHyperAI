# 7.42 五轮离线审查：拉野、对线与守塔

本次修改只进入优势路小野拉兵支路，不碰游戏客户端、不把历史实战当新版本验证。基线是 9107144732（b31173a）及 9107123606（4ec44c0）。优先检验「线压在敌方一塔，拉己方一波或部分兵，下一次交汇往己方塔外移动」；塔下、弱势核心与双方阵容必须分开评价。老攻略只借机制思路，不搬旧地图点位或固定秒数：[ZQuixotix 的兵线均衡](https://www.youtube.com/watch?v=AK1SuqoNOic)、[小野拉兵演示](https://www.youtube.com/watch?v=hFxx4eHp_1E)；[Valve 7.42 说明](https://www.dota2.com/patches/7.42?l=tchinese)。本轮没有职业比赛片段或 Max+ 私房数据作为证据。

## 问题清单

| # | 证据与问题 | 状态 |
| --- | --- | --- |
| 1 | 原判定仅量离己塔多远，己塔后方同距离也能被认成推进。 | 以兵线有向进度修复，反例通过 |
| 2 | 普通游走的离线检查对短距拉野一刀切；当前线已推出、核心安全，仍可能完全不拉。反过来旧版没有要求一定有在线核心。 | 拉野专用条件：核心在场、有血量、没刚被攻击，必要时确认塔与核心身边安全 |
| 3 | 原 ETA 用营地中心与 Bot 移速估算，没用实际被打的中立单位、弹道或较慢的移动速度。 | 切到实际目标计算 |
| 4 | 原逻辑命中一个宽 ETA 窗口就立刻出手，偏早会让野怪先回头。 | 有计划释放时刻，提前则等待 |
| 5 | 拉野等候期间兵线可走过交点，旧逻辑仍会出手。 | 出手前重新查合法来兵 |
| 6 | 远程攻击出手不等于打中或拉到仇恨，旧版可提前跑开。 | 等野怪实际仇恨才移动 |
| 7 | 旧成功条件只要野怪打到一个己方 IsCreep 单位，孤兵/召唤物可误报。 | 至少两个真正己方线兵接战才计确认；不把确认当回线结果 |
