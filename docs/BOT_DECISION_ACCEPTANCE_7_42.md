# 三连败后的决策验收清单

基线：9107444522、9107461081、9107476754，行为版本 `e2d7e93`。这一页说明代码切入点，不把离线通过写成实战已解决。

| 复盘缺口 | 代码切入点 | 实战判断 |
| --- | --- | --- |
| 1. 未掉塔已落后 | 按边路收入、出手原因和 10 分钟净资产分别诊断；不补贴经济 | 10 分钟团队净资产差和双边路收入，按局拆 |
| 2. 核心恢复后仍离线 | 修坐标接口，安全返线可压过无效撤退；有敌或路径不明不强走 | 恢复后重新接触兵线的时间 |
| 3. 小退变成整路撤 | 仅在可脱离追击并维持兵线附近时短退，否则保留真正撤退 | 短退占比、回线是否送死 |
| 4. 够得到但补不掉 | 提早判断一步可达的兵，走路、转身、前摇和弹道不重复计时；用日志区分没有兵、准备补、等待出手 | 安全可达而未收掉的样本，不能把所有漏兵算为手法 |
| 5. 双辅助掩护及资源分配 | 返线时补近端掩护，紧急补刀和反补保留；回线/撤退可以取消拉野队列；远距离角色不瞎调 | 辅助是否掩护，是否抢核心可接的兵，是否虚拉野 |
| 6. 少飞后仍有资源空窗 | 返线优先；前版安全短刷、归线取消和早期跨路限制保留 | TP 次数之外，统计 5–15 分持续无资源 |
| 7. 到塔太晚 | 分配按施法/攻击影响时限，不把只到附近或读条完成当成清线完成 | 首次有效输出时间 |
| 8. 到塔但清错目标 | 优先取正在打塔的单位，匹配实际射程和可走站位；保留符文和高地接管保护 | 首波 12 秒伤害、攻城车和主要塔伤何时停止 |
| 9. 通用团战过于依赖原始战力 | 近距离有交战迹象时加实际输出区间：接触、普攻、双抗、有限法力预算、己方 CD、可见敌方施法；区间重叠由原模型兜底 | 按开前可见信息，核对误接/漏接 |
| 10. 放弃大团时可能还有局部交换 | 塔已锁定才计塔伤，上下界分离；暴露核心时取消，价值参考等级与可见装备，连招缺位不能假定 | 是否真的保塔或换掉有价值目标，是否损失核心 |
| 11. 站位、集火、技能跟不上 | 可兑现的集中伤害纳入共同选敌；见到团控交出后只减一点威胁；保留绕正面、分散和救核心规则 | 实测先手对象、跟进秒数、被团控人数 |
| 12. 赢团没有接资源 | 推塔先估打完/安全磨塔并撤离的时限，来不及则取可见安全线；肉山受回场时限和守塔名额约束 | 30/60 秒实际塔伤、线兵或目标；自家高地打赢无可转换时不记失败 |
| 13. 收线/外飞后无人接反推 | 对可见将到的中线预留人；覆盖时限含行动和回程，主清线者不花回防 TP 换远处收益 | 下一波反推是否有人能先出手 |

不读取敌方隐藏 CD、隐藏装备或雾中单位数据来抬高战斗判断。区间只覆盖短窗内可知的部分输出；不会模拟每个英雄的所有技能组合、完整买活/赏金账目，或承诺赢三局。固定复测版本、角色、游戏配置与录像，逐局归档。需要通过录像才能关闭的项仍标记为待验证。
