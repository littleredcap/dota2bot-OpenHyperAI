# 7.42 技能接入检查：先核对施法与目标，再评估出装

本轮只处理前次审计留下的具体技能，不把静态 KV 或离线 Mock 当游戏行为证据。7.42 的新增或重做神杖与魔晶遵守同一条规则：在成熟社区攻略、Bot 实际施法能力和出装机会成本分别验证之前，维持已有默认购买暂缓（神杖包括 Blessing 的合成路径）。对局掉落、自定义出装不等于批准恢复默认购买。**尸王 Zombie Bite 和默认魔晶维持暂缓，本阶段不实施、不恢复。**

## 逐项接入结论

“检查条件”是将来实机测试需要证实的条件，不代表相应信号已经能通过 Bot API 可靠读取。

| 技能／施法者 | 指令与目标 | 接入前应查的条件与否决项 | 本轮 |
| --- | --- | --- | --- |
| 兽王 Ancient Thunderhide | 兽王、神杖、无目标；`beastmaster_summon_thunderhide` | 验证持有升级后句柄可见、已学习、可施放；确认现有受控 Thunderhide 的归属及存活状态。先测确认为首次召唤；已有召唤物且过去三秒受伤时不可重召。验证加入现有召唤物控制逻辑，避免只召不控。 | 不新增自动施法；不恢复神杖。 |

| 陈 Holy Persuasion 自施 | 7.42 新增以陈自身为目标，延时召回受控野怪；与旧野怪目标分开。 | 验证自己属于合法目标、拉回的是预期己方单位，以及延迟结束时的实际位置。单独测试野怪正在完成推进／控制任务时不应随意召回。 | 不接入；不改原野怪目标逻辑。 |
| 戴泽 Through the Realm | 魔晶、投影期间的无目标子技能；`dazzle_through_the_realm`。 | 确认物理本体、投影和施法句柄属于同一戴泽；本体被缠绕或束缚时不可用。瞬发不等于传送，本体仍要移动；可在眩晕时施放但不会解除眩晕。应验证移动方向和终点安全。 | 不接入；不恢复魔晶。 |

| 米波拾取／Fling | 魔晶；拾取与投掷是两个阶段，`meepo_fling_release` 不是旧神杖 MegaMeepo 的句柄。 | 先实测拾取入口、分身所有权、目标类别与携带状态转移，再分别验证向敌方目标、己方 Meepo 或地面投掷的实际合法性、释放句柄和落点。未证实已携带时不得投掷。 | 不接入；不恢复魔晶。现有 Dig 防空检查保持原样。 |

## 验证与恢复门槛

- 先验证实际挂载的句柄，不把全局 ID 存在当作英雄／召唤物已解锁。观察指令发出后的真实状态变化，不能仅凭日志里出现一次调用。
- 每个候选至少覆盖一个成功场景和一个相近的否决场景；记录游戏版本、代码 SHA、升级来源与实机结果。实机之前不默认启用本表标为“不接入”的技能。
- 拉席克只验证移除旧触发和收窄旧撤退分支。没有证明它的新缴械策略比旧策略更强。编织者只做离线回归。运行：
  ```sh
  lua5.1 tests/test_7_42_leshrac_nihilism.lua
  lua5.1 tests/test_7_42_weaver_time_lapse.lua
  npm run check:deferred-aghanims
  ```
- 恢复默认出装是独立决定：社区攻略成熟、对应英雄／位置有明确购买时机和替代品比较、Bot 的技能产生真实收益，再逐个解除 [暂缓购买](AGHANIMS_DEFERRED_7_42.md)，而不是有了句柄就恢复。
