# 不依赖对手脚本的防线与收线调度

本轮继承 [战后协调规则](BOT_POST_FIGHT_COVERAGE_7_42.md)。天地星只用于保持既有比赛基线，不是运行时输入。没有查询对手 Bot 脚本名、版本、工坊 ID、阵容或比赛 ID；威胁只用已看见的塔伤、兵、英雄接触、公开状态和可走到的位置。

| 改动 | 本轮接入 | 仍须验证或补齐 |
|---|---|---|
| 首塔后转线、前后塔交接 | 三路选站得住的第一座塔或被压的兵营。明显来不及救残塔，不向前送人；改派后塔。保留实际已到位的守将，外出前按返程预算复核。 | 无战斗的首塔后轮转尚未做完整的地图价值排序；实战要看中路接替是否及时。 |
| 全队经济 | 己方半区可见安全兵波唯一分配。先扣掉守备与正在打架的人，有机会时优先给赶得上的落后核心。其余沿用营地认领和原推进计划。 | 未把所有中立营地、肉山与补状态统一做求解，需测中期实收兵线金而非单局胜负。 |
| 团战和符文 | 旧集火逻辑保留；能就地接触时更倾向打正在压低血核心的敌人，禁止为追击放弃不能空的防线；符文可用于把建筑预计存活时间延长到已分配守将的到位时间。 | 不声称已经识别所有技能链，也没有将支援分工扩到全部英雄技能。 |
| 多路压力和机动 | 同时有两路明确压力可派不同人；主清线先于掩护，用同一候选表避免重派。单个无护送小兵不额外招回第二人。TP 和先知独立远程传送接受共用返程预算，紧急撤退保留。 | 并非所有远程技能均接入；当前无明显信号时，仍以暴露的中路作为基地最低覆盖。 |
| 边路观测 | 可选前十分钟补刀指令、反补、护核和让位诊断，和既有拉野事件一起用。它记录下令，不冒称成功；实战从录像核对兵的真实转向与经济。 | 在不同对手、换边的复测中验证补刀和保命装时间，诊断未覆盖所有消耗或补给动作。 |

离线案例不指定友军英雄名：不同路的双重推进、残塔跳过、单兵不召回备用、TP 未落地不算接班、两个安全波由同编号场景的不同角色收取、低经济核心在能准时到达时可优先。推塔/刷钱/回防仍有生产入口联合回归。复测同阵容只验证和旧版本的差异；要验证泛化，另做换边以及不同对手或阵容，不能拿一场胜负当结论。
