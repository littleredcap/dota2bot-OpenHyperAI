## 离线验收结果

最终工作区实际运行了全部 **39 组 Lua 5.1 回归**，并对 Git 跟踪的 **324 个 Lua 文件**逐一执行语法检查，全部通过。关键正反例如下。

- 静止攻城车不会续报到塔，随后真正推进、开始攻塔会重报。同一建筑上的跨路扫描不会覆盖另一条路的移动记录。[联合模式回归](../tests/test_issue159_push_defend_joint.lua) · [守塔分工回归](../tests/test_7_42_mid_tower_response.lua)
- 高地清线者与掩护者保留各自站位，塔后已有可打目标时可以直接出手，引导和危险站位仍受保护。建筑刚倒和遗迹刚受威胁时，旧任务会释放。[联合模式回归](../tests/test_issue159_push_defend_joint.lua)
- 低血、缺蓝时继续恢复，恢复充分的边路核心可以立即选择安全回线。两名收线者能分出先后，有效认领从三兵延续到一兵，目标或安全条件消失则撤销。[回线回归](../tests/test_side_lane_reentry.lua) · [对线回归](../tests/test_7_42_laning_decisions.lua) · [收线回归](../tests/test_issue159_push_defend_joint.lua)
- 攻击队友的塔、不可见蛇棒不计入本体集火。敌方晕弹不会冒充友军控制，友方晕弹命中后用实际控制剩余时间续控。小 Y 在第二名可见敌人面前放弃主动枷锁，仍可打断关键引导。[撤退和诊断回归](../tests/test_7_42_defense_stall.lua) · [接战回归](../tests/test_7_42_combat_transitions.lua) · [英雄技能回归](../tests/test_7_42_ability_parameters.lua)
