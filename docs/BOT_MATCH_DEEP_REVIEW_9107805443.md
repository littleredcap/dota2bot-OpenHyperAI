## 对照、反例与验收

- **更正 19:42 的旧归档。** 19:28.60 敌骷髅王第一次倒下并重生，19:42.57 同一英雄再次倒下。天辉击杀从 6 加到 7，实际是 5 对 4。此后 60 秒 OHA 对建筑造成 0 点伤害，同时自己上 T1 被打掉；当时多个队友远离敌塔，不能拿这段证明“赢了两个敌人却不推”。32:13 天辉骷髅王的第一条命同样没有给对方增加人头。
- **28 分钟并非整段都停。** 27:59.67 五人都在上高地，各自最近敌兵约 102–533。在 27:50–28:40 火枪对线兵造成 3,168、对英雄造成 347 伤害，龙骑分别为 2,707、172。28:44 的全队同停发生在随后中高地。27:41 骷髅王有重生，28 分钟的上述两段没有死亡或 TP。
- **金钱与建筑技能。** 天辉 20/25/30 分钟净资产差为 −3,023 / −10,128 / −10,940，20–30 分钟直接收线 83:121，旧版为 87:121。31:14 和 31:40 两次雕纹都有真实兵线。下一层约 37:14.03 才可用，基地 37:13.80 已毁。全场没有买活，现有数据不足以确认关键死者当时具备买活资格，无法据此认定漏买活。
- **诊断和下一局。** 使用 `TraceLaneDecisions` 时，新日志按英雄记录无普攻区间起点、前后模式与岗位、任务建筑、可见攻击目标和线兵距离、累计路程与净位移、当前动作和是否引导，开始普攻时记录恢复时刻。日志能解释任务，与录像中的实际首次命中配对才算有效动作。复测优先检查空塔等待能否解除、真实推进是否误放、高地首发清线延迟、赢团后安全收线数和 20–30 分钟净资产差。当前所有实战指标均属于旧行为版本。

## 离线验收结果

最终工作区实际运行了全部 **39 组 Lua 5.1 回归**，并对 Git 跟踪的 **324 个 Lua 文件**逐一执行语法检查，全部通过。关键正反例如下。

- 静止攻城车不会续报到塔，随后真正推进、开始攻塔会重报。同一建筑上的跨路扫描不会覆盖另一条路的移动记录。[联合模式回归](../tests/test_issue159_push_defend_joint.lua) · [守塔分工回归](../tests/test_7_42_mid_tower_response.lua)

- 低血、缺蓝时继续恢复，恢复充分的边路核心可以立即选择安全回线。两名收线者能分出先后，有效认领从三兵延续到一兵，目标或安全条件消失则撤销。[回线回归](../tests/test_side_lane_reentry.lua) · [对线回归](../tests/test_7_42_laning_decisions.lua) · [收线回归](../tests/test_issue159_push_defend_joint.lua)
