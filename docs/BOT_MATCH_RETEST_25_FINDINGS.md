# 7.42 三连复测：25 项验收清单

基线：`26d3d74`，录像 9107592293 / 9107627429 / 9107653557。[证据和反例](BOT_MATCH_DEEP_REVIEW_26D3D74.md)。本页不把离线测试通过等同于实战修复。相同配置连打三局，每局先登记再开下一局。新旧各三局，先逐个比较胜负以外的过程指标；没出现对应战况记“未覆盖”。

| # | 候选版改动或仍未独立修复的假设 | 下一轮验收 |
|---|---|---|

| 12 | 各路提前纳入同一分工，未覆盖的更紧迫塔不再被已覆盖塔遮住。 | 连续转线时按轨迹查是否不要所有人追同一路。 |
